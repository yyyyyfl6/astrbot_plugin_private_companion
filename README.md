## 它做什么

原插件在 AstrBot 上用后台任务"间断唤醒"来模拟角色的连续生活。QQ Agent 本身就是连续对话的工作流，
所以移植版只保留核心思路，用**副 API 维护一个持续进行的长任务**，再**按不规则的时间提示主模型主动发消息**：

| | 怎么做 |
| --- | --- |
| **跟着当前人格** | 后台的一切（排日程、推进生活、做梦、成长）都用**这个会话当前正在运行的人格**——和主对话同一张角色卡（经宿主 `cap.context.persona` 读，多人格切换后跟着变）。多人格时每个人格各过各的日子、各有各的梦和成长；插件设置里的「角色设定」只是补充 |
| **人格交接** | 多人格 `/切换` 时，QQ Agent 自己会把**聊天内容**总结成交接摘要给新人格；陪伴插件补上宿主不知道的那一半：旧人格**自己的生活**（此刻在做什么、今天做过什么、心情——明确标成"那是之前那位的事"）、今天**已经主动找过几次**（早安道过了就别再道）、**已经追问过的事**。口径和宿主一致（转述，非亲历），一直挂到下一次切换；切换后下一次主动往后推一段，每日上限按人算、切人格不清零；私聊日记记下当天是哪个人格陪的，换了人格后那几天标"转述" |
| **生活长任务** | 副 API 每天按「角色设定」排一份节目单日程；之后每隔一段（围绕「生活推进间隔」上下浮动）推进一次：刚发生了什么、心情、有没有想跟对方说的念头。状态一直挂在陪伴对象的私聊背景里，主模型每轮都知道自己正过着怎样的一天 |
| **主动联系** | 每次在「最少 ~ 最多间隔」之间随机取下一次时间（不规则）。由头依次来自：起床后的早安 → 生活里攒下的念头 → 昨天日记里的待跟进 → 久未联系。只是**提示主模型**来一次主动唤醒，发不发、说什么由主模型按人设决定 |
| **分寸** | 免打扰时段不动；每人每天有上限；上一条对方没回，24 小时内不再追；对方正在聊时自动往后推 |
| **私聊日记** | 记下每天对方说过的话，第二天凌晨由副 API 写成"那天发生了什么 + 待跟进"，最近几天进背景，更早的由模型用 `recall_diary` 按日期 / 关键词翻 |
| **手机连接** | 对方手机上的安卓「陪伴终端」App 把**位置**（地点名 / 标签）、**电量与充电**、**正在用的应用**（私密类自动显示成"私密应用"）、**运动健康摘要**推过来，实时挂进角色的背景（不给模型坐标）；**到了一个新地方**或**电量很低**时成为主动由头（仍过免打扰与上限）。协议与原插件的移动网关一致，同一个 App 直接连；App 里改角色的称呼也认 |
| **一起房间** | 在 App 里开「一起看」（填在看什么，边看边聊）、「一起读」（贴一段正在读的文字，角色读完说感受）、「一起工作」（手机屏幕共享 / 手动上传截图，角色像坐在旁边一样看一眼说两句）。角色在房间里用**当前人格**、知道自己此刻的生活；离开后一句话（"刚和 TA 一起看了《千与千寻》"）挂进私聊背景、记进角色今天的生活；房间开着时不主动打扰 |
| **陪伴游戏** | 井字棋、五子棋、掷骰竞分、二十一点（规则与角色的走法都由代码算，不花副 API）；海龟汤（副 API 出题、只答"是 / 不是"）、你画我猜（你画、角色看图猜）。结束时角色说一句，战况记进背景 |
| **屏幕共享** | App 开着屏幕共享时推来的截图：有「一起工作 / 一起看」房间就进房间；没有就每 10 分钟看一眼，记一句"TA 在做什么"进背景（要求不写聊天内容、账号、金额；只留最新一帧在内存） |
| **熟人卡（关系网）** | 每个人一张：称呼、关系、生日、相处方式、备注，外加**每日反思**从 TA 的话里自动记下的印象。挂进和 TA 私聊的背景（不是陪伴对象的人也行）；模型也能用 `update_card` 记下 TA 明确告诉你的事 |
| **互动纪念日** | 每日反思从对方**原话**里提取"第一次一起看电影"这类日子（日期就是那句话真实发生的那天，宁缺毋滥），也可以手动加；生日读熟人卡。当天进背景（带"几周年"），起床一小时后作为一次主动由头 |
| **梦境** | 每天起床后，副 API 依据昨天的生活与心情做一个梦，上午挂进背景，想说就说 |
| **跟进与跨窗口** | 日记里的"待跟进"问过一次就不再追；陪伴对象刚在群里说过的话（只有 TA 本人的、30 分钟内）会挂进私聊背景，转到私聊时能自然接上 |
| **表达学习** | 从获准会话里**别人**的说话方式归纳"在什么场合、用什么说法、怎么用、什么时候别用"（带原话依据），每天凌晨学一次进**待审核**；在小屋里采纳 / 改写 / 驳回，采纳的才挂进背景，驳回和退役的不会再被学回来；分享包导出 / 导入。默认关（它会读群聊里别人的话） |
| **成长记录** | 每天凌晨回顾这个人格昨天的生活，练过的技能慢慢攒经验升级（Lv1~10），偶尔记里程碑；排第二天日程时参考还在练的事，也挂进背景 |
| **陪伴小屋（页面）** | 插件详情里的一页：总览（此刻 / 节目单 / 今天发生的 / 念头 / 梦 / 陪伴对象 / 接下来的日子）、关系网、日记与生活、纪念日、表达学习、成长、主动记录、手机（含屏幕共享与开着的房间）。所有按钮直接控制插件行为 |
| **工具** | `life_status`（对方问"你在干嘛 / 今天过得怎样"时以它为准）、`recall_diary`、`update_card` |

主对话的人设、模型、记忆都不受影响：插件只给背景、只提请求；白名单、作息、观察 / 暂停模式、
每日预算等守卫都在 QQ Agent 原有的链路上。

## 安装

> 接入要求、注意事项与自查清单见 [INTEGRATION.md](INTEGRATION.md)。

需要 QQ Agent **0.9.12+ 且支持插件接口 apiVersion 3**（`llm` / `context` / `wake` / `inbound` / `page` 五项能力，
以及 inbound 的文本响应与 `inbound.headers`、`llm` 的图片输入，见 qq-agent-plus 的 `docs/PLUGINS.md`）。

1. 控制台左侧「插件」→ 打开「启用插件功能」；
2. 「手动安装」选 [`dist/private-companion-0.6.0.tar.gz`](dist/private-companion-0.6.0.tar.gz)，
   或填它的直链 + sha256（见 [`index-entry.json`](index-entry.json)）；
3. 在「已装」里点「启用」，打开插件设置填：
   - **陪伴对象 QQ**（最多 4 个，只陪这些人的私聊）；
   - **副 API**：供应商 id（设置 → 模型 API 的供应商卡片上）和模型，建议选便宜的（要用看图类功能就选能看图的）；
   - **角色名 / 角色设定**：给副 API 排生活用，几句话即可；
   - 主动联系的间隔、每日上限、免打扰时段。

启用后每 5 分钟巡检一次；插件详情里的「陪伴小屋」能看到今天的日程、此刻状态、人格交接与手机配对情况。

### 连手机（可选）

1. **让手机够得着服务器**：插件设置 → 手机连接 → 勾「给手机单开一个端口」，端口默认 `6322`，保存后**重启服务**。
   这个端口只提供本插件的路径、不暴露控制台；记得在安全组 / 防火墙放行它（或者放到 HTTPS 反向代理后面）。
   只要位置 / 状态的话也可以不单开端口，用控制台端口：`http://服务器:3210/plugin-hooks/private-companion`
   （**一起房间与游戏只在独立端口上能开**：房间是网页，控制台端口与控制台同源，宿主不在那里给插件网页）。
2. **插件设置 → 手机连接**：勾「启用手机连接」，填一个 ≥24 位的随机**配对令牌**（加密保存、不回显），
   「绑定的 QQ」留空 = 第一个陪伴对象；按需打开位置 / 应用 / 运动健康共享。
3. **手机端**：陪伴终端 App 里填网关地址 `http://服务器:6322`（用控制台端口就填上面那个带 `/plugin-hooks/…` 的地址）和同一个配对令牌，完成配对；
   之后位置与状态由 App 自动上报（数据只放内存，位置 15 分钟、应用 15 分钟、健康 1 小时过期，插件重启即清）。
4. **一起房间 · 游戏 · 屏幕共享**（插件设置里同名一组）：勾「允许从手机开一起房间与游戏」；要截图 / 你画我猜 / 屏幕共享就再勾
   「让角色看图」（副 API 的模型要能看图）与「接收手机屏幕共享」。放在 HTTPS 反代后面、或手机用的地址和服务器看到的不一样时，
   填「房间公开地址」（如 `https://companion.example.com`），App 拿到的房间链接以它开头。

原插件用高德做逆地理（中国境内）；移植版不调地图服务，地点名直接用 App 上报的"地点 / 标签"，海外也能用。
视频 / 语音通话（要实时音视频链路）与中国象棋暂不提供，App 调到会收到说明。屏幕共享的截图走 `POST /screen/frame`
（移植版新增，JSON `{ image: "data:image/jpeg;base64,…" }`，约 170KB 以内）；App 不支持推帧时，在「一起工作」房间页里手动上传截图也一样。

## 和原插件的差别

移植版是"核心思路的重写"，不是逐行翻译：原插件约 17 万行 Python + 11 万行前端（陪伴小屋），
大量功能依赖 AstrBot 宿主或外部设备。目前移植了生活长任务、主动联系、私聊日记、熟人卡、互动纪念日、梦境、跟进与跨窗口承接、
表达学习、成长记录、手机连接（含屏幕共享）、一起房间、陪伴游戏，以及「陪伴小屋」页面，并跟主对话的人格系统打通；
没移植的见 PORTING.md 的路线。

## 对 QQ Agent 本体的改动

插件本体全部在这个仓库里，不放进 qq-agent-plus。QQ Agent 原有的插件接口做不了"调副 API（含看图）/ 给会话挂背景 /
请主模型主动发消息 / 读当前人格 / 设备入站（含给设备的网页）/ 插件自带页面"，所以宿主加了通用的插件接口 apiVersion 3
（qq-agent-plus 的 `src/plugins/agent-caps.js`、`inbound.js`、`v3.js`、`ui/pages/plugin-page.js`，对上游已有文件只留几行接线）。
宿主里没有任何陪伴专属的代码、配置键或请求头：手机独立端口的开关在本插件的设置里，App 用的 `X-Companion-Mobile-Token`
头由本插件在 manifest 的 `inbound.headers` 里声明。
